Hubungkan database Firebase

Masukkan konfigurasi Firebase satu kali pada perangkat ini. Nilai konfigurasi web Firebase bukan password; keamanan data tetap diatur melalui Authentication dan Firestore Rules.

Ambil dari Firebase Console → Project settings → Your apps → Web app.

Masuk ke Kartu Stok

Akun dibuat oleh pengelola di Firebase Console → Authentication → Users → Add user. Tidak ada pendaftaran publik dari aplikasi.

Scan QR / transaksi stok

Stok keluar tidak boleh membuat saldo negatif. Koreksi stok memakai qty positif untuk menambah atau negatif untuk mengurangi.

Input massal pembelian / penjualan

Impor CSV berisi banyak transaksi sekaligus. Satu baris untuk satu kode part. Gunakan tanggal format YYYY-MM-DD, kode part persis seperti master, dan qty bilangan bulat positif. Semua baris akan divalidasi sebelum disimpan; penjualan yang membuat stok negatif akan ditolak.

Transaksi akan tercatat satu per satu di riwayat dan stok aktual diperbarui di database Firebase untuk semua perangkat. Jangan impor file yang sama dua kali.

Master Parts

Impor awal 2.404 part dilakukan satu kali. Kode yang sudah ada diperbarui nama/grup/kategori/batasnya, sementara stok aktual yang sudah berjalan tidak ditimpa. Untuk stok awal baru, pilih hanya saat database masih kosong.
